# Embedded PDF Fonts

PDF reports use Google Noto Sans fonts with HarfBuzz shaping. Font files are downloaded at setup/runtime only when missing from this directory; no system font is assumed.

Source: https://github.com/google/fonts/tree/main/ofl

Families used: Noto Sans, Noto Sans Devanagari, Noto Sans Kannada, Noto Sans Telugu, Noto Sans Tamil, and Noto Sans Malayalam.
